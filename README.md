## How to use this draft

1. Replace every `[[PLACEHOLDER]]` with the real consortium data (legal names, PICs,
   staff, rates). Placeholders are the only content that must not survive to submission.
2. Transfer the text into the official Part B template downloaded from the Portal
   Submission System — the template on the Topic page is for information only.
3. Keep the assembled Part B under 70 pages, readable, accessible and printable.
4. Mirror the detailed budget table figures into the online Part A summarised budget
   (in case of discrepancy, the online table prevails).
